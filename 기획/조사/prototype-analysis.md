# 프로토타입 분석

## 확인 파일

`driving_game/{main,config,sensor,car,traffic_light,world,test_game}.py`, Arduino 스케치.

|구성|현재 상태|웹 이식 결정|
|---|---|---|
|센서|roll 단일값, roll/pitch, WME 프레임 파싱. 중앙 보정과 단절 처리|파서 계약과 결함 사례만 재사용. WME 실제 축 의미는 장치 검증 필요|
|조향|연속 조향, dead zone, smoothing|LEFT=-1/CENTER=0/RIGHT=1 + 히스테리시스로 재설계|
|가속|pitch 및 W/S, Space 제동|pitch 제거. Space 전진/Control 후진, 둘 다/둘 다 없음 정지|
|셋업|중앙 후 좌우앞뒤 확인, 확인 상태 유지|중앙 3초→좌→중앙→우→중앙만 유지|
|차량/월드|Ursina 전역 런타임, 단순 이동·충돌|TS 순수 상태/기하 모듈과 Three.js 렌더링 분리|
|신호|주기·정지선 통과·재진입 감지|검증 가능한 시나리오 이벤트로 재설계|
|점수|가상 달러와 파산|최종 제품에서 제외. 공식 규칙 버전과 사건 기록으로 대체|
|저장/로그인/AI|완성 웹 서비스 구조 없음|별도 백엔드·DB 설계 필요|

## 실행 증거

복사된 폴더에서 `.venv/bin/python -B -m unittest -v test_game` 실행.

```
Ran 21 tests in 0.026s
OK
```

실제 이번 세션 반환값이며 기존 동작 테스트다. 새 요구사항의 성공이나 실제 하드웨어 방향 검증을 뜻하지 않는다. pyserial loopback은 물리 센서가 아니다. 센서 포트를 열거나 펌웨어를 변경하지 않았다.
