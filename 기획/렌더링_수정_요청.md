# 작업 요청 — 3D 주행 화면 렌더링 깨짐 수정

## 상황

`전진만할게요` 웹의 주행 화면(3D)이 깨졌다. **경사로를 넣은 커밋 `2e5e726` 이후 생긴 회귀다.**
그 전에는 정상이었으니 이 커밋의 `web/frontend/src/sim/render3d.ts` 변경분이 1순위 용의자다.

```bash
git show 2e5e726 -- web/frontend/src/sim/render3d.ts web/frontend/src/sim/engine.ts
```

## 증상 (장내기능 코스, 운전석 시점)

1. **차 앞 노면이 사라졌다.** 아스팔트가 안 보이고 초록 잔디(바닥 평면)가 그대로 드러난다.
2. **차선만 공중에 떠 있다.** 흰 점선·실선은 그려지는데 그 아래 도로 면이 없다.
3. **경사로 구간만 검은 사다리꼴 덩어리**로 멀리 떠 보인다. 지면과 이어지지 않고 떠 있으며 면이 검게 칠해진다.
4. 결과적으로 도로가 아니라 잔디밭 위에 검은 판이 떠 있는 그림이 된다.

## 무엇을 건드렸나

경사로를 실제 고도로 구현하면서 다음을 바꿨다.

- `engine.ts` 에 `elevationAt(definition, s)` / `gradeAt(definition, s)` 추가.
  코스 정의에 `ramps: [{from, to, rise_m}]` 가 들어간다. 장내기능 코스는
  `[{from: 77.13, to: 95.13, rise_m: 1.6}, {from: 95.13, to: 103.13, rise_m: -1.6}]`.
  `elevationAt` 은 평지 구간에서 정확히 0 을 돌려준다(확인함).
- `render3d.ts` 의 도로 리본 생성부(`strip` 함수 안)에서 정점 Y 에 `elevationAt` 을 더했다.
- 차선(`courseLine`)의 각 조각 Y 에도 구간 평균 고도를 더했다.
- 운전석 카메라 높이와 시선 목표점에도 고도를 더했다.
- 피니시 라인(체크무늬·기둥·가로대)을 새로 그린다.

## 확인해 볼 지점

순서대로 의심스럽다.

1. **고도를 안 따라가는 요소들.** 도로 본체만 올렸고 나머지는 평면 y 에 남아 있다.
   - 바닥 평면(`ground`, y = -0.08, 1200×1200 평면) — 경사로 아래가 비어 공중에 뜬 것처럼 보인다.
     경사로 옆면(둑)을 채우거나, 도로 아래를 받치는 면을 같이 만들어야 자연스럽다.
   - 갓길 스트립(`strip(..., -lane-1.7, -lane-0.45, ...)` 등), 어린이보호구역 바닥 표시,
     횡단보도 타일, 신호등·표지판 기둥, 이벤트 마커 스프라이트, 주행 결과 화면의 경로 선.
   - 이것들이 아직 평면이라면 경사 구간에서 도로와 어긋난다.
2. **검게 보이는 면 → 법선 문제.** Y 가 변하는 리본에 `computeVertexNormals()` 를 그대로 쓰고 있다.
   삼각형 인덱스 방향(winding)과 법선이 뒤집혀 조명을 못 받으면 검게 나온다.
   `material.side = THREE.DoubleSide` 로 바꿔 보면 원인인지 바로 갈린다.
3. **z-fighting / 렌더 순서.** 도로(y=0)와 바닥(y=-0.08) 간격이 0.08 뿐이다.
   차선은 y=0.035 라 살아남고 도로 면만 지는 상황이면 깊이 충돌이다.
   바닥을 더 내리거나 `polygonOffset` 을 쓴다.
4. **카메라가 노면 아래로 들어갔을 가능성.** 운전석 카메라 Y 에 `elevationAt(sim.s)` 를 더하는데,
   `sim.s` 와 실제 차 위치가 어긋나면 노면을 뚫고 아래에서 위를 보게 된다. 그러면 도로 뒷면(검정)이 보인다.
