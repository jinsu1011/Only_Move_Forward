# 전진만할게요 — 필기·주행 통합 운전면허 학습

1·2종 보통 운전면허 준비자가 필기 오답과 브라우저 주행 연습 기록을 함께 돌아보고, 근거가 확인되는 AI 설명으로 다음 연습을 정하는 학습 보조 서비스입니다. 공식 시험·실차교육을 대체하지 않습니다.

- **필기**: 주제별 연습, 제출 후 정답·조문 근거 공개, AI 오답 코칭
- **주행**: MPU-6050 기울기 핸들(또는 키보드)로 기본조작·도로 코스 연습. 사건은 누적 기록하고, 서버가 입력을 다시 재생해 확정
- **AI 리포트**: 서버가 계산한 필기 약점·주행 사건 통계만 인용해 다음 연습 제안

## 빠른 시작

```bash
./시작.sh
cd web/backend && ./.venv/bin/python -m uvicorn app.main:app --port 8010
npm --prefix web/frontend run dev   # http://localhost:5180
```

이어받기 절차는 `이어서작업.md`, 결정과 구조는 `PROJECT_HEAD.md`, 진행 상황은 `기획/PROGRESS.md`.

## 조작

| 모드 | 전진 / 후진 | 조향 |
|---|---|---|
| 센서 | ↑ / ↓ | 핸들 좌우 기울기 (민감도: 둔감·보통·민감) |
| 키보드 | W / S | A / D |

R 즉시 정지·다시 정렬 · Esc 일시정지(한 번 더 누르면 기록 저장 후 나가기)
