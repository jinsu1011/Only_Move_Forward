### dbdiagram.io 경고 3건 — 확인 후 그대로 둠

`official_scoring_rules.category_id` · `driving_events.rule_id` · `ai_jobs.answer_id` 세 개가 nullable 인데 `ref: >` 로 적혀 있다는 경고다.
세 컬럼 모두 `db.py` 에서 실제로 nullable 이 맞다(각각 134·193·206행). dbdiagram.io 는 `>?` 로 바꾸라고 제안한다.

**바꾸지 않았다.** `>?` 는 dbdiagram.io 전용 확장이라 공식 파서가 거부한다 — `@dbml/core` 3.14.1 과 최신 10.1.1 모두 `Expected " " but "?" found` 로 파싱 실패했고, 인라인 `[ref: >? ...]` 와 독립 `Ref:` 블록 양쪽에서 실패한다.
접수 요건은 "dbdiagram.io 에서 오류 없이 렌더링"이고 현재 오류는 0이다. nullable 여부는 컬럼 정의에 `not null` 이 없는 것과 각 컬럼 Note 로 이미 드러나 있다.

## 3. 검증 방법 (재실행)

도구는 `검증도구/`에 있다. `npm install` 후 실행한다. Chrome 설치가 필요하다.

```bash
node 검증도구/validate.mjs 9반_P286_김진수_전진만할게요-API.yml 9반_P286_김진수_전진만할게요-DB.dbml
../../web/backend/.venv/bin/python 검증도구/contract_dump.py ../../web/backend /tmp/calls.json
node 검증도구/contract_check.mjs 9반_P286_김진수_전진만할게요-API.yml /tmp/calls.json
node 검증도구/pdf.mjs "$PWD/개요PDF/slides.html" "$PWD/9반_P286_김진수_전진만할게요-개요.pdf" /tmp/prev
```

- `contract_dump.py` — 임시 DB로 실제 FastAPI 앱을 띄워 27개 동작 전부와 주요 오류(400·401·403·404·409)를 호출해 응답을 저장한다. AI 키는 비워 대체 경로로 동작한다.
- `contract_check.mjs` — 저장한 응답을 명세 스키마로 검증한다. **선언하지 않은 필드도 실패로 처리**한다. 일부러 필드를 추가·타입을 바꾼 응답으로 실패하는 것을 확인했다(역검증).
- `capture.mjs` / `recapture.mjs` — 실행 중인 웹(5180)을 조작해 화면을 캡처한다. 실제 AI 호출이 일어난다.
- `render_tools.mjs` — DBML → ERD 이미지(mermaid, 로컬), 로컬 Swagger UI 캡처.

### 4차 — 발표 별첨 다시 씀
- 이전 별첨은 어두운 배경에 본문과 다른 레이아웃이었고, 내용도 본문을 요약한 게 아니라
  따로 쓴 글이었다. 웹 화면이 한 장도 들어가 있지 않았다.
- **본문과 같은 밝은 레이아웃**으로 바꾸고, 쪽마다 본문 몇 쪽을 줄인 것인지 각주에 적었다.
- 실제 웹 화면 캡처 7장을 넣었다(대시보드·코스 선택·문제 풀이·출발 전 점검·주행·주행 결과·AI 오답 해설)
  과 도구 캡처 2장(ERD·Swagger).
- **시연 타이밍 쪽을 새로 만들었다**(+0초/+10초/+20초/+40초/+55초에 무엇을 보여 주고 무엇을 말할지).
  시연이 막히면 본문 캡처로 대신한다는 대비도 적었다.
- 구성: 표지 · 배경 01~03 · 해결 · 화면 흐름 · 시연 · 설계 ①②③ · 고민과 다음 단계 = 11쪽
- 채점 기준 대응: 목적·배경·타깃(배경 01~03), 기능(해결), UI 흐름과 화면 캡처(화면 흐름),
  예외(화면 흐름 각주), 데이터 모델·API(설계 ③), 설계 상의 고민과 다음 단계(마지막 쪽)
- 말투는 참고 PDF(`미니프로젝트1` 개요) 기준으로 맞췄다. 한 문장에 사실을 몰아넣지 않고 끊어 썼다.

### 3차 — 말투 · 별첨 · 하드웨어
- **말투** — 제목 22개와 본문 다수를 고쳐 썼다. 모든 제목이 “~합니다”로 끝나 기계가 쓴 것처럼 읽혀서,
  짧은 단정문·명사구로 리듬을 흩었다(예: “서버가 입력 기록을 다시 재생해 확정한 사건만 결과로 남깁니다”
  → “브라우저 말을 그대로 믿지 않는다”).
- **하드웨어 소개 장 추가**(8쪽) — 회로도·납땜 작업·조립 완료 사진 3장과 부품/출력/실측 요약.
  발표에서 10초 정도로 넘기는 용도. 사진은 `자료/하드웨어/`.
- **발표 별첨 10장 추가**(27~36쪽) — 어두운 배경의 발표용 슬라이드. 기술서와 내용은 같고 분량만 줄였다.
