01 판정은 서버가 쥔다

필기 정답은 검수 데이터, 주행 사건은 서버가 재생한 결과가 기준이다. 브라우저 결과와 다르면 “불일치 → 서버 기준”으로 띄운다.

02 AI 는 설명만 한다

AI 가 받는 건 서버가 만든 스냅샷뿐이고, 인용 ID 와 수치는 서버가 다시 검사한다. 측정하지 않는 거울 확인·반응시간은 아예 분석하지 않는다.

03 확인 못 한 기준은 안 켠다

별표26 57항목을 자동 채점(A) 0개 · 연습 표시(B) · 안내만(C) 으로 나눴다. 공식 문제은행과 모의고사는 이용 조건과 검수가 끝나기 전까지 꺼 둔다.

04 센서는 서버를 안 거친다

조향이 늦으면 못 쓰니 Web Serial 로 브라우저가 직접 읽는다. 케이블이 빠지거나 창이 밀리면 바로 정지시킨다.
